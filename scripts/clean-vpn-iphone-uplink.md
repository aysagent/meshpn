# Стабильное имя USB-модема iPhone

Для одного USB iPhone с Linux-драйвером `ipheth` используется имя `iphone0`.
Правило сопоставляет драйвер, а не MAC, серийный номер, модель платы или USB-порт.
Оно подходит A7Z, Zero и другим Linux-платам с systemd-udevd/ipheth.
Установка драйвера, pairing/usbmuxd и DHCP должны уже работать.

```sh
bash scripts/clean-vpn-iphone-uplink.sh plan
sudo bash scripts/clean-vpn-iphone-uplink.sh install
```

Команда создаёт только `/etc/systemd/network/10-clean-vpn-iphone.link` и
перечитывает правила udev. **Живой интерфейс не переименовывается:** имя начнёт
действовать при следующем подключении телефона или загрузке. Раннее правило
имеет приоритет перед стандартным именованием `enx…`.

Перед активацией обновить native control plane: версии до поддержки `iphone0`
отклоняют это имя. В VPN рекомендуется `uplink: "auto"`, тогда Wi-Fi остаётся
резервным маршрутом; явное `uplink: "iphone0"` также разрешено. Только имя
не меняет метрики и приоритет сети.

Существующее networkd-правило `[Match] Driver=ipheth` продолжает работать.
Если DHCP/NAT/мониторинг сопоставляют старое имя буквально, их нужно отдельно
перенести до активации. Штатные конфиги чужих служб скрипт не переписывает.
Для уже установленного дополнительного доступа к админке:

```sh
sudo /opt/meshpn-admin/node admin/management-access.mjs enable \
  --interface=iphone0 --subnet=172.20.10.0/28 --port=80 --mdns --apply
```

Эта команда перезапускает web/mDNS, сохраняет USB-доступ и использует текущие
имя/пароль админки. Подсеть проверяется по фактической DHCP-аренде iPhone.
До появления `iphone0` дополнительный listener недоступен; админка на `usb0`
остаётся рабочей. Проверить после подключения: `ip -br address`,
`networkctl status iphone0`, состояние VPN и доступ через его exit.

Откат правила:

```sh
sudo bash scripts/clean-vpn-iphone-uplink.sh uninstall
```

Удаляется только файл с точным собственным содержимым. При следующем подключении
вернётся системное имя; привязки админки и явный VPN uplink тоже нужно вернуть.
Правило независимо от VPN и снимается этой командой, а не uninstall VPN.
Одновременное подключение нескольких iPhone не поддержано: для них нужны
отдельные правила и имена. Уже занятое чужим устройством `iphone0`, несколько
подключённых ipheth и изменённый сторонний `.link` при install отклоняются.

Порядок `.link`, `Driver=` и приоритет `NamePolicy=` описаны в
[systemd.link](https://www.freedesktop.org/software/systemd/man/latest/systemd.link.html).
