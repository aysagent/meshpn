# Тридцать минут нового musl engine и HTTP-профиля

После коротких проверок актуальный ARM64 musl engine
`0c87b6e4b83b0fb4ace4e694c86637035bc8e9c72c9f88f697247136d255e273`
прошёл отдельные 30 минут с четырьмя независимыми combo-клиентами и LAN.
[Receipt](../fixtures/clean-vpn-native-musl-http-soak-20261031.json).

Профиль — `chromium-156-bounded-http-v1`, SHA файла
`baaf251e0de975de15d1d501b2630235f3210fe15efe49e3dfcb326e72d99e2f`.
Во время прогона отдельный `sha256sum /config/profile.json` подтвердил этот SHA
на всех четырёх клиентах. Runner теперь передаёт выбранные bytes генератору
bundle, сохраняет SHA в receipt; `CVPN_MULTI_PROFILE` задаёт файл до создания
ресурсов. Первый подготовительный прогон до исправления передачи профиля
был прерван и не считается успешной проверкой нового профиля. Его собственные
ресурсы удалены через journal recovery; неудачный отчёт сохранён отдельно.

Итог: **14106** mixed rounds (3528/3526/3527/3525), 1800 секунд нагрузки,
321 sample, ни одного перезапуска native engine. Квота одной идентичности
заполнена 64 relay-соединениями; остальные три клиента выполнили каждый по
8 packet и 8 relay запросов без отказов. Ресурсы восстановились, SIGTERM чистый.

В обычной фазе peak RSS: exit 6264 KiB, клиенты 5824–5996 KiB. Финальная
медиана RSS ниже начальной на 452–496 KiB; это измерение musl allocator и
нагрузки в данном стенде, не универсальная гарантия памяти. Квотная pressure
фаза отдельно отражена в `settled`/`pressure`; её нельзя смешивать с normal peak.

Параллельно в той же VM шли компиляция/тесты, поэтому результаты не являются
latency/throughput benchmark. Это внутренние container namespaces с настоящими
TUN и отдельными LAN/ключами, не физический WAN или отдельный DNS leak audit.
Новый внешний pcap этот долгий прогон не снимал; независимая сверка того же
image/profile была в [коротком combo runtime](clean-vpn-native-containers-20261031.md).
Рабочие Radxa/VPS и сеть Mac не менялись. Cleanup удалил собственные контейнеры,
тома и сети; исходный daily engine этим прогоном не заменялся.
