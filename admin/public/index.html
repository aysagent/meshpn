Последние операции


VPN
Выключение VPN сохраняет kill switch. Прямой выход разрешается отдельным действием.
Выключение защиты останавливает VPN и разрешает прямой выход в интернет. После загрузки платы штатная защитная служба снова включается.
Режим установленного VPN. Его смена требует согласованного изменения движка и маршрутов.
Профиль проверяется native engine до сохранения. На установленном native сервисе изменения требуют перезапуска. Смена endpoint требует согласованного обновления маршрутов и защиты.


DNS и диагностика
Сертификаты —
Сроки локальных сертификатов проверяются по часам устройства. На клиенте это CA, а не сертификат удалённого exit; проверка соединения и цепочки здесь не выполняется.
Текущая версия native engine использует фиксированные upstream. Миграция системного DNS не выполняется из этой страницы.
Профили браузера и туннеля
Импорт native-профиля
Импорт сохраняет профиль, но не активирует его. Выбор — в настройках VPN. Захват браузера и исполняемый профиль — разные документы.

Маршрутизация
Правила по IP, доменам и Geo-IP пока не реализованы. Существующие маршруты не меняются при сохранении настроек админки.


Wi-Fi
Системные профили показаны только для просмотра; их настройки задаются в системе. Статус «Доступна» означает, что имя сети было видно в последнем сканировании. До 256 сохранённых сетей; выше приоритет — раньше выбор. Сохранённые сети ищутся автоматически, даже когда SSID скрыт. WPA2 Personal и открытые сети.

Внешний наблюдатель
Отдельный tcpdump снимает реальное соединение с exit. Сравнение использует байты ClientHello из pcap, а не отчёт VPN. Запустите захват и затем переподключите VPN, чтобы увидеть новое соединение.

Клиенты exit
Имя клиента определяет внутреннее имя <имя>.mpn. Адрес назначается автоматически и остаётся за клиентом. DNS-зона подключается отдельно. «Доступ разрешён» не означает, что клиент сейчас подключён.

Устройство
Адрес name.local публикуется только на USB. Системное имя Linux не меняется. Доступ по USB-IP сохраняется.
Пароль
Смените стандартный пароль для изменения настроек.
